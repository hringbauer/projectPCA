# projectPCA
Project genomes onto pre-computed principal components widely used in ancient DNA. Enables fast analysis without re-computing the principal components.


### List of available PCAs
List of available PCAs bundled with projectPCA. The bracket denotes the code you can use to all this PCA.

- **HO Westeurasia (HO)**:
Standard Western Eurasian PCA, which is widely used in aDNA studies.

- **HO Eurasian (EURO)**
Standard whole-Eurasian PCA, widely used in aDNA studies. Excellent to resolve west versus east Asian ancestry (on PC1)

- **Fine-scale Europe (EU)**:
Fine-scale PCA of European variation. Traces back to Joscha Gretzinger and Stephan Schiffels. High resolution for West versus East European ancestry (on PC2, ideally plotted on x axis to reflect geography)
